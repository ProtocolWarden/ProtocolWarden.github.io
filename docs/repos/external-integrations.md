# External Integrations

This page groups repos that are relevant to the ecosystem but are not core
ProtocolWarden semantic authority.

## Categories

- Forked dependency
- Adapter candidate
- Backend candidate
- External capability source

## Examples

- firecrawl
- PraisonAI
- Wan2GP
- openclaw
- Zonos-API
- neuro-game-sdk

## Retired forks (ADR 0005, 2026-05-18)

- **kodo** — retired; replaced by [TeamExecutor](teamexecutor.md)
- **Archon** — retired; replaced by [DAGExecutor](dagexecutor.md)

## Rule

These repos are not equal to core platform repos. They only become platform
components when the contract and boundary story is explicit.
